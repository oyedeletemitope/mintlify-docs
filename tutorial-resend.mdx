## Overview

Resend is a developer-first email API. It lets you send transactional emails from your Node.js app using a simple REST API and an official SDK. This tutorial walks you through sending your first email from start to finish.

By the end, you will have a working script that sends a real email and know how to handle the three most common errors.

## Prerequisites

Before you start, make sure you have:

- **Node.js 18 or later** installed. Run `node -v` to check.
- **A Resend account.** Sign up free at [resend.com](https://resend.com).
- **A verified sender domain or email.** Resend requires you to verify ownership of the address or domain you send from. You can do this in the Resend dashboard under Domains.
- Basic familiarity with running commands in a terminal.

<Note>
If you are on Windows, use `node -v` in PowerShell or Command Prompt to confirm your Node.js version.
</Note>

## Step 1: Create your project folder

Open your terminal and run these commands one at a time:

```bash
mkdir resend-demo
cd resend-demo
npm init -y
```

`npm init -y` creates a `package.json` file with default settings. You should see output like this:

```
Wrote to /resend-demo/package.json:
```

## Step 2: Install the Resend SDK

Run this command inside your project folder:

```bash
npm install resend
```

When the install finishes, you will see something like:

```
added 5 packages in 2s
```

## Step 3: Get your API key

Log in to your Resend dashboard at [resend.com/api-keys](https://resend.com/api-keys). Click **Create API key**, give it a name, and copy the key. It starts with `re_`.

<Warning>
Keep this key private. Do not commit it to a public repository.
</Warning>

## Step 4: Write the send script

Create a new file called `send.js` in your project folder and paste this code:

```javascript send.js
const { Resend } = require('resend');

const resend = new Resend('re_YOUR_API_KEY');

async function sendEmail() {
  const { data, error } = await resend.emails.send({
    from: 'you@yourdomain.com',
    to: ['recipient@example.com'],
    subject: 'Hello from Resend',
    html: '<p>This is my first email sent via Resend.</p>',
  });

  if (error) {
    console.error('Error:', error);
    return;
  }

  console.log('Email sent. ID:', data.id);
}

sendEmail();
```

Replace `re_YOUR_API_KEY` with your actual key. Replace `you@yourdomain.com` with your verified sender address.

## Step 5: Send the email

Run the script from your terminal:

```bash
node send.js
```

If everything is set up correctly, you will see:

```
Email sent. ID: 12345abc-6789-...
```

Check your recipient inbox. The email should arrive within a few seconds. You can also see delivery status in the Resend dashboard under **Emails**.

## Troubleshooting

Here are the three most common errors and how to fix them.

### 401 Unauthorized

**Cause:** Your API key is wrong, expired, or missing.

**Fix:** Double-check the key in your script. Make sure you copied the full key starting with `re_` and did not add extra spaces.

### 422 Unprocessable Entity

**Cause:** The sender address is not verified in Resend.

**Fix:** Log in to the Resend dashboard and verify the domain or single address you are sending from. The `from` address in your script must match exactly.

### Cannot find module 'resend'

**Cause:** The SDK was not installed in the current folder.

**Fix:** Make sure you ran `npm install resend` inside your project folder, not outside it. Check that a `node_modules` folder exists.

---

If the email arrives but looks broken, check that your `html` value is valid HTML. Resend also accepts a `text` field if you prefer plain text.
