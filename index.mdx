# Documentation Assessment - Day 10

This site was built as part of the Documentation Assessment Course using Mintlify. It brings together two deliverables from earlier in the course: the GitHub REST API reference from Day 7 and the Resend email tutorial from Day 9.

## What is in this site

<CardGroup cols={2}>
  <Card title="Tutorial" icon="book-open" href="/tutorial-resend">
    A step-by-step guide to sending your first email with the Resend API in Node.js. Includes prerequisites, numbered steps, expected output, and a troubleshooting section.
  </Card>
  <Card title="API Reference" icon="code" href="/api-reference">
    Reference documentation for three GitHub REST API endpoints: Get a user, List repository issues, and Get a repository.
  </Card>
</CardGroup>

## About this site

This site was built using [Mintlify](https://mintlify.com). The source files are plain MDX, version-controlled on GitHub, and linted with Vale on every push via GitHub Actions.

**Stack:**
- Static site generator: Mintlify
- Content format: MDX
- Linter: Vale with custom write-good rules
- CI: GitHub Actions
